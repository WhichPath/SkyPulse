# SkyPulse 离线行政区划与逆地理编码数据模块

本目录包含 SkyPulse 离线逆地理编码（Offline Reverse Geocoding）的完整处理管线、拓扑校正算法以及生成的多边形与点位全量数据集。

---

## 1. 模块设计与解耦原则

为了摆脱对任何第三方商业地图 SDK（如高德开放平台、百度地图等）与运行时逆地理网络 API 的依赖，解决 GPS 逆地理编码 2~3 秒的网络延迟、限流及隐私泄露风险，本项目建立了一套**完全自包含、完全离线、拓扑自洽**的毫秒级逆地理编码系统。

* **完全解耦**：本目录下的构建脚本 `build_offline_geodata.py` 独立运行于构建期，不依赖 Android 项目运行时代码；
* **单向输入输出**：构建输出的产物直接作为静态资源打包进 App，或由应用端在构建时打包入 `assets/geo/`；
* **可复现性**：数据管线可随时重新执行以适配民政部未来发布的最新区划标准。

---

## 2. 数据源权威性与优先级金字塔

数据融合严格遵循**“最新官方源 > 最新社区源 > 较老官方源 > 较老社区源”**的权威性金字塔：

1. **第一级（绝对权威法定基准）**：
   * **民政部 2026/2025.251231 官方全国四级行政区划底册（国家地名信息库）**
   * 提供全国 **39,188 个** 县级以下法定乡镇、街道办事处、区公所的标准 12 位行政代码、所属 6 位县码及标准名称。
2. **第二级（法定空间外壳）**：
   * **自然资源部天地图 2024 全国县级行政区划边界图（GS(2024)0650）**
   * 提供全国 2,898 个法定县级行政区的高精度多边形边界，作为定位判定的第一阶段硬约束。
3. **第三级（最新社区/测绘源更新）**：
   * **OpenStreetMap (OSM) 2026 全国多边形与全要素地名图层**
   * 用于提取天地图 2024 未包含的新建制实体（如 500157 两江新区、232761 加格达奇区）的行政边界，以及 19,917 个乡镇街道的法定面要素质心。
4. **第四级（统计局/高德测绘点位）**：
   * **国家统计局/高德 adcode 数据集**
   * 提供 3.5 万个乡镇级驻地坐标及数十万个村委会/社区居委会点位。
5. **第五级（较老官方设防标准）**：
   * **GB 18306-2015《中国地震动峰值加速度区划图》官方国家标准乡镇点位**
   * 补充未发生改制的历史成熟乡镇驻地。

## 3. 核心算法：拓扑紧密填充（Watertight Topology）

针对天地图 2024 版缺失“两江新区（500157）”与“加格达奇区（232761）”多边形，且直接粘贴 OSM 多边形会因描边精度产生重叠或缝隙的问题，算法实施了**拓扑硬外壳剪裁算法**：

### 两江新区（500157）拓扑剪裁
1. **构建法定硬外壳**：提取天地图中原江北区（500105）、渝北区（500112）、北碚区（500109）的多边形联合体（`Union Shell`）；
2. **内缩剪裁**：将 OSM 的两江新区多边形与该法定硬外壳求交集（`Intersection`），消除沿长江/嘉陵江岸线的微小测绘外溢；
3. **差集细分**：从原江北区、渝北区、北碚区中分别减去（`Difference`）剪裁后的两江新区多边形；
4. **结果保证**：
   ```text
   新江北区 + 新渝北区 + 新北碚区 + 两江新区 == 原始法定总外壳
   ```
   **100% 紧密填充，零空隙、零重叠，数学上绝对无缝密闭！**

### 加格达奇区（232761）拓扑剪裁
* 同理，从内蒙古自治区鄂伦春自治旗（150721）中求差集，精准剥离出独立的加格达奇区（232761）。

最终生成包含 **2,900 个** 完备县级行政单元的 `counties_2026.geojson`。

## 4. 乡镇点位消歧与改制更名位置继承

针对民政部 39,188 个乡镇底册，算法执行了多层级穿透与位置继承：

1. **管理体制变更位置继承**：撤乡设镇、撤镇设街仅管理体制变动的，名称采用民政部 2026 最新法定标准，坐标严格继承原有点位；
2. **村居下探聚合**：当乡镇办事处本身坐标缺失时，自动下探至其管辖的下属村委会/居委会，以居委会重心作为乡镇驻地；
3. **兵团番号正则解耦**：将兵团复合命名（如“六十六团金梁镇”）拆分为番号与镇名分别在 OSM 图层中检索；
4. **县界包含校验（In-Polygon Verification）**：所有社区/OSM 候选点必须严格通过其所属县级多边形的空间包含校验，杜绝跨区越界。

## 5. 文件清单说明

* **`build_offline_geodata.py`**：全流程离线构建、拓扑剪裁与消歧映射执行脚本；
* **`build_mobile_assets.py`**：移动端二进制资产（`counties.bin` 与 `townships.bin`）编译器与空间哈希网格生成器；
* **`counties_2026.geojson`**：全国 2,893 个区县法定有效多边形面（已滤除 7 条天地图境界线，含两江新区 500157 与加格达奇区 232761 紧密填充面）；
* **`townships_2026.json`**：民政部 39,188 个乡镇街道全量官方标准字典（包含未完成 pending 单位）；
* **`townships_active.json`**：**移动端运行时激活空间字典**（严格收录 38,798 个具备可信真实经纬度的单位，专供空间最近邻匹配）；
* **`unresolved_townships.csv`**：未完成待补全单位清单（单列官方全称，包含大陆 129 个与港澳台 260 个、国外 1 个）；
* **`sources/ok_data_level3.csv`**：民政部三级行政区划代码标准字典备份，用于推导市辖区归属上级地级市/直辖市；
* **`build_stats.json`**：每次构建后的自动化统计指标记录。
